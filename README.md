# Shresth Thumbnail Portfolio

## Uploading to GitHub Pages
Upload the contents of this folder to the root of your GitHub repository.

## Updating thumbnails later
1. Put your new image inside `images/`.
2. Open `script.js`.
3. Copy one project line in the `projects` array and change the image, title and category.
4. Commit the changes on GitHub.
5. GitHub Pages will publish the update automatically.

Before publishing, replace:
- `YOUR_EMAIL@example.com`
- `YOUR_INSTAGRAM`

with your real contact details in `index.html`.

No build tools or coding software are required.
